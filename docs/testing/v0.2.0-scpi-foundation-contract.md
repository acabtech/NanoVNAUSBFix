# v0.2.0 SCPI foundation and sweep parity contract

This is the recorded contract for the M1/M2 slice in
[`0004-scpi-foundation-sweep-parity.patch`](../../patches/0004-scpi-foundation-sweep-parity.patch).
The responses below are the expected shape; the exact serial and sweep timing
values differ per unit. Run the commands over USBTMC on hardware to validate a
build, and diff the shapes against this file.

## System commands

```bash
riglol scpi --usb usb:0x0483:0x5740 '*IDN?'
# NanoVNA-H,USBFix,1.2.50,<24 hex UID>

riglol scpi --usb usb:0x0483:0x5740 ':SYST:VERS?'
# 1999.0

riglol scpi --usb usb:0x0483:0x5740 ':SYST:SER?'
# <24 hex UID>

riglol scpi --usb usb:0x0483:0x5740 ':SYST:BUILD?'
# <build date and time>

riglol scpi --usb usb:0x0483:0x5740 ':SYST:ERR:COUN?'
# 0
```

## Error queue

```bash
riglol scpi --usb usb:0x0483:0x5740 ':VNA:SWE:POINTS 9999'
# -222,"Data out of range"

riglol scpi --usb usb:0x0483:0x5740 ':SYST:ERR:COUN?'
# 1

riglol scpi --usb usb:0x0483:0x5740 ':SYST:ERR?'
# -222,"Data out of range"

riglol scpi --usb usb:0x0483:0x5740 '*CLS'

riglol scpi --usb usb:0x0483:0x5740 ':SYST:ERR?'
# 0,"No error"
```

Malformed or unknown commands return a parseable error and never require a
power cycle.

## Sweep geometry and state

```bash
riglol scpi --usb usb:0x0483:0x5740 ':VNA:SWE:START 1000000'
riglol scpi --usb usb:0x0483:0x5740 ':VNA:SWE:STOP 30000000'
riglol scpi --usb usb:0x0483:0x5740 ':VNA:SWE:CENT 15000000'
riglol scpi --usb usb:0x0483:0x5740 ':VNA:SWE:SPAN 10000000'
riglol scpi --usb usb:0x0483:0x5740 ':VNA:SWE:POINTS 101'
riglol scpi --usb usb:0x0483:0x5740 ':VNA:SWE:EXEC'

riglol scpi --usb usb:0x0483:0x5740 ':VNA:SWE:START?'
# 10000000
riglol scpi --usb usb:0x0483:0x5740 ':VNA:SWE:STOP?'
# 20000000
riglol scpi --usb usb:0x0483:0x5740 ':VNA:SWE:POINTS?'
# 101

riglol scpi --usb usb:0x0483:0x5740 ':VNA:SWE:STAT?'
# RUN
riglol scpi --usb usb:0x0483:0x5740 ':VNA:SWE:TIME?'
# <integer milliseconds>
riglol scpi --usb usb:0x0483:0x5740 ':VNA:SWE:RATE?'
# <integer points per second>
```

## Single, continuous and abort

```bash
riglol scpi --usb usb:0x0483:0x5740 ':VNA:SWE:SINGL'
riglol scpi --usb usb:0x0483:0x5740 ':VNA:TRIG:STAT?'
# IDLE

riglol scpi --usb usb:0x0483:0x5740 ':VNA:SWE:CONT'
riglol scpi --usb usb:0x0483:0x5740 ':VNA:TRIG:MODE?'
# CONT

riglol scpi --usb usb:0x0483:0x5740 ':VNA:ABOR'
riglol scpi --usb usb:0x0483:0x5740 ':VNA:SWE:STAT?'
# PAUSE
```

## Acquisition controls

```bash
riglol scpi --usb usb:0x0483:0x5740 ':VNA:POW 3'
riglol scpi --usb usb:0x0483:0x5740 ':VNA:POW?'
# 3

riglol scpi --usb usb:0x0483:0x5740 ':VNA:BAND 1000'
riglol scpi --usb usb:0x0483:0x5740 ':VNA:BAND?'
# <integer Hz near 1000>

riglol scpi --usb usb:0x0483:0x5740 ':VNA:AVER:COUN 8'
riglol scpi --usb usb:0x0483:0x5740 ':VNA:AVER:STAT?'
# 1
riglol scpi --usb usb:0x0483:0x5740 ':VNA:AVER:COUN?'
# 8
riglol scpi --usb usb:0x0483:0x5740 ':VNA:AVER:RES'
riglol scpi --usb usb:0x0483:0x5740 ':VNA:AVER:STAT OFF'
```

Averaging is in-place and costs no additional RAM. `*RST` also disables it.
